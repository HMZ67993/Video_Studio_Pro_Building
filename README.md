# HMZ Video Studio Pro — استوديو مونتاج محلي (PyQt6)

تطبيق ويندوز لتحرير الفيديو والصوت والنصوص، بمعالجة محلية 100%، واجهة عربية (RTL) وإنجليزية (LTR)، مبني وفق معيار **HMZ-Bytes-App** ويُنتَج كـ **ملف EXE واحد** عبر Nuitka.

## 1. المزايا الرئيسية

- **شاشة رئيسية** عند التشغيل: مشروع جديد/فتح/استيراد، بدء سريع بمقاس الفيديو (16:9 / 9:16 / 1:1 / 4:5)، **بطاقات آخر المشاريع** (تثبيت، إظهار في المجلد، إزالة)، «ما الجديد»، شريط إصدار جديد، واسترداد العمل بعد إغلاق مفاجئ. حفظ سريع Ctrl+S.
- **مظهر أنعم:** نمط Fusion موحّد، ألوان وأشرطة تمرير ومنزلقات وقوائم مُعاد تصميمها، شاشة تمهيدية أثناء التحميل، شريط أقسام جانبي مضغوط، وحقول مفتّش مزدوجة لتقليل التمرير، وقائمة «☰ المزيد» تجمع المظهر واللغة والدليل.
- تايم لاين متعدد المسارات: تحديد متعدد، سحب وقص الحواف، التقاط مغناطيسي، علامات، تكبير، **قوائم زر أيمن** للمقاطع والمسارات والمسطرة والفراغ.
- **محرر نصوص كامل:** خط وحجم وعريض/مائل/تحته خط ومحاذاة وتباعد، لون وشفافية، حدود، ظل، توهج، صندوق خلفية، انعكاس وقلب، حركة دخول/خروج، قوالب سريعة. يُفتح بالنقر على النص في المعاينة أو التايم لاين (أو نقرتين، أو Enter، أو زر أيمن).
- ألوان وLUT، سرعة وSpeed Ramp، كروما وأقنعة، إطارات مفتاحية، انتقالات، ترجمة SRT، تصدير MP4/MOV/GIF/WAV.
- **دمج الصوت عند التصدير** (FFmpeg، AAC) مع المستوى والتلاشي والمعادل والسرعة وطبقة الصوت، وتصدير H.264 بجودة (عالية/متوازنة/مضغوطة) وتسريع NVENC اختياري إن نجحت تجربته فعلاً.
- **معاينة صوتية** أثناء التشغيل، **حفظ تلقائي واسترداد** بعد الأعطال، صور مصغرة على التايم لاين، ذاكرة إطارات لتسريع المعاينة.
- **أداة قص (Crop)**، **تسجيل من الميكروفون**، و**ملصقات** (38 ملصقاً أصلياً، 13 منها متحرك، مكتبة شبكية مصغرة مع فلاتر ومعاينة حركة، استيراد ملفات أو مجلدات PNG/GIF/WebP، وتسميات عربية/إنجليزية لملصقاتك)، ومسار ملصقات يُنشأ عند الحاجة فقط مع مسارات إضافية عند التداخل.
- **حركات دخول/خروج/تكرار** لأي مقطع مرئي، **لقطة PNG** من الإطار الحالي، **ملاءمة التايم لاين** و**سدّ الفراغات**، وإفلات الملصقات على التايم لاين أو المعاينة.
- **معاينة أكثر سلاسة:** رسم الإطارات على خيط خلفي باستخدام لقطة مستقلة من المشروع، وتخزين رسم التايم لاين وإعادة رسم المؤشر فقط أثناء التشغيل. معالجة دمج الطبقات تعمل على نطاق الطبقة الظاهر فقط.
- **أدوات تحليل/ذكاء حقيقية:** اكتشاف الإيقاع، اكتشاف المشاهد، تقليل الضوضاء، حذف الصمت تلقائياً (مع تراجع Ctrl+Z)، وترجمة تلقائية Whisper وعزل الشخص ONNX. محرك AI والنماذج الاختيارية تُنزّل عند الطلب من داخل التطبيق؛ لا حاجة إلى Python أو pip على جهاز العميل.
- دليل داخلي مفصّل (F1، 33 قسماً بالعربية والإنجليزية)، نافذة About، صفحة «المزيد من تطبيقاتنا».
- ترخيص مزدوج: Gumroad + سيريال يدوي موقّع Ed25519، تحديث موقّع، سلامة ملفات اختيارية.

## 2. متطلبات التشغيل

Windows 10/11 (64-bit). للتطوير: Python 3.12 (3.10–3.12 موصى بها). **FFmpeg غير مضمَّن في البرنامج** (لا نوزّعه): يُنبَّه المستخدم عند أول تشغيل إن لم يوجد ويُعرض عليه «تثبيت الآن» (تنزيل من gyan.dev مع التحقق من SHA-256 إلى `%APPDATA%\HMZVideoStudioPro\ffmpeg`)، ويُسأل مجدداً عند تصدير ملف فيه صوت، وإلا يُصدَّر الفيديو بلا صوت مع إبلاغه. FFmpeg مطلوب لدمج الصوت ومعاينته وتصدير WAV وأدوات الإيقاع والضوضاء والترجمة وإنشاء Proxy.

## 3. تشغيل نسخة التطوير

```bat
python -m pip install -r requirements.txt
python video_studio.py
```

الاختبارات: `python -m pytest -q tests` (تعمل بـ `QT_QPA_PLATFORM=offscreen`).

## 5. اللغات والثيمات والإعدادات

عربية/إنجليزية بتبديل فوري، ثيم داكن/فاتح/النظام و5 ألوان تمييز. الإعدادات في `%APPDATA%\HMZVideoStudioPro\settings.json` (حفظ ذري، وتلف الملف لا يعطّل البرنامج). `update_check_hours` يضبط فترة فحص التحديث (الافتراضي 6).

## 6. المجاني والمدفوع

المجاني: كل المزايا مع `FREE_OPERATIONS = 5` عمليات تصدير ناجحة (لا تُحتسب الملغاة/الفاشلة). بعدها يلزم التفعيل.

## 7. إعداد Gumroad

1. أنشئ المنتج وأضف خاصية License Keys.
2. ضع `GUMROAD_PRODUCT_ID` و`GUMROAD_BUY_URL` في `video_studio_license.py`.
3. التفعيل يستدعي API مع `increment_uses_count=true` **مرة واحدة**؛ إعادة التحقق لا تزيد العداد. خطأ الشبكة يُعامَل كخطأ شبكة وليس «مفتاح غير صالح».
4. `MAX_DEVICES = 3` **حد مرن**: يعتمد على عدّاد Gumroad ولا يمثل سجل أجهزة حقيقياً. للحد الحقيقي يلزم Backend (غير مرفق).

## 8. توليد المفاتيح وإصدار السيريالات

شغّل `tools\license_tool.bat` (قائمة إنجليزية) أو الأوامر مباشرة:

```bat
python tools\issue_serial.py keygen                       :: مرة واحدة: 5 مفاتيح مستقلة + يكتب المفاتيح العامة في الكود تلقائياً
python tools\issue_serial.py issue --machine * --customer "Ali" --days 365
python tools\issue_serial.py issue --machine ABCD-1234 --customer "Sara" --nbf 2026-12-01 --expires 2027-12-01
python tools\issue_serial.py revoke --serial VSP1-...     :: أو --jti
python tools\issue_serial.py sign-payment --price "500 EGP" --instapay name@instapay --whatsapp 2010xxxxxxx
python tools\issue_serial.py release --version 1.1.0 --url https://github.com/USER/REPO/releases/download/v1.1.0/HMZVideoStudioPro.exe --sha256 <HEX> --notes "..."
python tools\issue_serial.py products-template
```

- المفاتيح الخاصة تُحفظ في `tools\keys\` (خارج Git والـ ZIP). **انسخها احتياطياً خارج الجهاز**؛ فقدانها يعني عدم القدرة على إصدار سيريالات متوافقة.
- `keygen` لا يعمل إن وُجدت مفاتيح إلا بـ `--force` (يُبطل كل السيريالات السابقة).
- السيريال: `VSP1-<payload>.<sig>`؛ الحمولة تحوي المنتج، رقم الجهاز (`*` لأي جهاز)، بداية الصلاحية `nbf`، الانتهاء `e` (أو دائم)، و`jti` للإلغاء. مجال توقيع مستقل لكل غرض فلا يُعاد استخدام توقيع.
- بعد `keygen` **أعد البناء** حتى تُضمَّن المفاتيح العامة في EXE.

## 9. update.json و products.json (مستودع GitHub عام)

أنشئ مستودعاً **عاماً منفصلاً** (بيانات فقط، بلا مصدر ولا مفاتيح)، وارفع إليه `tools\output\update.json` و`products.json`. الروابط الافتراضية في `DEFAULT_UPDATE_URL` (`video_studio_license.py`) و`DEFAULT_PRODUCTS_JSON_URL` (`video_studio_store.py`) — غيّرها لاسم مستخدمك.

صيغة `update.json`: `version,url,sha256,notes,update_sig,revoked,revoked_sig,payment,payment_sig`. التطبيق **يعرض فقط** المعلومات ويفتح رابط https؛ لا يحمّل ولا يشغّل شيئاً. لا يُعرض إصدار أقدم. البيانات غير الموقّعة تُتجاهل ولا تُخزَّن.

## 10. التحقق الدوري والعمل دون إنترنت

- فحص التحديث: عند الإقلاع وكل 6 ساعات (قابل للضبط). `REVERIFY_DAYS = 7`، `OFFLINE_GRACE_DAYS = 14` لمفاتيح Gumroad. السيريال اليدوي يعمل دون إنترنت.
- حماية ضد تراجع الساعة: لا يرجع الوقت الفعّال إلى ما قبل آخر تشغيل.
- حالة الترخيص نسختان موقّعتان HMAC؛ التلاعب يُعاقَب بإنهاء التجربة.

## 11. بناء ملف EXE واحد

**محلياً على Windows:** ثبّت Python 3.12 (64-bit) وVisual Studio Build Tools (Desktop development with C++) — أو دع Nuitka ينزّل MinGW عند أول بناء — ثم:

```bat
build.bat
```

ينفّذ: فحص Python والمترجم ← تثبيت المتطلبات الأساسية فقط ← pytest ← Nuitka `--onefile` ← توقيع اختياري ← SHA-256 ← **تشغيل EXE بـ `--selftest`**. يبقى EXE خفيفاً ولا يضمّن مكتبات AI. حزمة AI المنفصلة تُبنى في GitHub Actions وتُنشر في Release باسم `ai-runtime`، ثم ينزّلها التطبيق تلقائياً عند أول طلب لميزة Whisper أو عزل الشخص. الناتج المحلي: `dist\HMZVideoStudioPro.exe` و`dist\SHA256.txt`. ضع `icon.ico` بجانب `build.bat` (اختياري). للبناء المحلي الذي تريد أن ينزّل AI تلقائياً، عرّف متغير البيئة `HMZ_AI_REPOSITORY=OWNER/REPOSITORY` قبل تشغيل `build.bat`؛ البناء من GitHub Actions يضبطه تلقائياً.

> **محرك AI عند الطلب:** البناء الافتراضي ينتج EXE صغيراً. GitHub Actions ينشئ أيضاً `HMZ_AI_Runtime_Windows_Py312.zip` كحزمة مستقلة وينشرها في Release ثابت `ai-runtime` مع SHA-256. عند ضغط المستخدم على تثبيت Whisper أو عزل الشخص، ينزّل التطبيق الحزمة ويتحقق من SHA-256 ويفكّها داخل `%APPDATA%\HMZVideoStudioPro\ai_runtime` ثم يحمّل النموذج المطلوب. لا يحتاج العميل Python أو pip. يجب أن يكون مستودع GitHub عاماً حتى يستطيع التطبيق تنزيل الحزمة دون تسجيل دخول.

**على GitHub (بدون جهاز Windows):** ارفع المشروع إلى مستودعك، ثم Actions ← **Build Windows EXE** ← Run workflow، أو ادفع وسماً `v1.0.0`. ينتج Artifact يحتوي EXE الخفيف وحزمة AI الاختيارية وملفات SHA-256. تُنشر حزمة AI أيضاً في Release ثابت `ai-runtime`. اجعل المستودع عاماً إذا أردت أن يتمكن التطبيق من تنزيل الحزمة تلقائياً دون تسجيل دخول. لا يحتاج البناء أسراراً.

> ملاحظات: أول EXE يستخرج نفسه إلى `%LOCALAPPDATA%\HMZ-Bytes\VideoStudioPro\<الإصدار>` (أسرع في التشغيلات التالية). قد ينبّه مضاد الفيروسات على ملفات onefile غير الموقّعة — وقّع الملف.

## 12. التوقيع الرقمي وIntegrity Manifest

- **Authenticode:** عيّن متغيري البيئة `SIGN_PFX` و`SIGN_PASSWORD` ثم شغّل `build.bat` (يستخدم signtool ويتحقق). بدونهما يُحذّر ولا يُوقَّع. لا تضع الشهادة في المشروع.
- **integrity.json (اختياري مع الملف الواحد):** إن وُجد `tools\keys\manifest.key` ينشئ `build.bat` ملف `dist\integrity.json` موقّعاً بجوار EXE. عند وجوده وعدم تطابقه يُعطَّل التصدير والتفعيل فقط. غيابه لا يمنع التشغيل. بما أن التوزيع ملف واحد، فالتوقيع الرقمي Authenticode هو الحماية الأهم.

## 13. المثبّت (Inno Setup)

افتح `installer.iss` في Inno Setup بعد `build.bat`. تثبيت بدون صلاحيات مسؤول، عربي/إنجليزي، اختصار سطح مكتب اختياري، ولا يتضمن أدوات المطور. عند الحذف يُشغَّل `--remove-integrations` وتُحذف ذاكرة الاستخراج فقط (لا بيانات المستخدم).

## 14. حدود الحماية الفعلية

أي ترخيص في برنامج Python/Nuitka يمكن لمهندس عكسي متمرّس تجاوزه؛ الهدف رفع الكلفة وحماية الاستخدام التجاري الطبيعي. لا Backend مرفق، فلا يوجد إلغاء فوري ولا حد أجهزة حقيقي لمفاتيح Gumroad. **استعادة الترخيص:** عند تغيير الجهاز يرسل العميل Machine ID الجديد فتُصدر له سيريالاً جديداً؛ مفتاح Gumroad يُعاد إدخاله ضمن الحد المرن.

## 15. قيود معروفة (صريحة)

- منحنيات السرعة (Speed Ramp) تؤثر على الصورة فقط؛ الصوت يتبع السرعة الثابتة للمقطع.
- جودة أدوات AI: الإيقاع والمشاهد والضوضاء خوارزميات كلاسيكية جيدة في الحالات الواضحة فقط؛ Whisper جيد مع الصوت النظيف؛ عزل الشخص أقل دقة من خدمات السحابة (الشعر/الحركة السريعة) وأبطأ. وجميعها أدنى من CapCut في الحالات الصعبة.
- لم يُختبر على جهاز حقيقي: تنزيل FFmpeg من الإنترنت (gyan.dev)، تسريع NVENC، تشغيل/تسجيل الصوت عبر QtMultimedia داخل EXE (يحتاج إضافات `multimedia` التي أُضيفت لأمر البناء)، تضمين حزم AI في Nuitka، وتنزيل نماذج Whisper/ONNX. المنطق الخلفي (دمج الصوت، التصدير، الإيقاع، المشاهد، الضوضاء، الأقنعة) مُختبَر بنصوص آلية وFFmpeg حقيقي.
- نموذج عزل الشخص الافتراضي U²-Net (Apache-2.0). إن استبدلته بنموذج آخر فراجع ترخيصه للاستخدام التجاري.
- لم تُجرَّب الواجهة على PyQt6 حقيقي ولا البناء على Windows في بيئة التطوير التي أُنتج فيها هذا المشروع (انظر تقرير التسليم).
